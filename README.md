# Kay's Case File: live vote

Live voting for a "two truths, one lie" presentation.

- **Phones:** https://kayleigh-meta.github.io/case-file/
- **Big screen (host):** https://kayleigh-meta.github.io/case-file/#host

Host controls sit at the bottom of the big screen (they brighten on hover): lock votes with a 3-2-1 countdown, reopen, reveal the lie, show/hide names, copy the voter link, and start a new round.

Votes travel through a public [ntfy.sh](https://ntfy.sh) channel, which keeps messages for 12 hours. One vote per device, no take-backs.
